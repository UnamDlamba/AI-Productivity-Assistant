# MarketMate AI

## Project Overview

MarketMate AI is an AI-powered Workplace Productivity Assistant designed to help marketing professionals, social media managers, agencies, brands, content creators, and students automate repetitive workplace tasks.

The platform improves productivity by using Artificial Intelligence to assist with email generation, meeting note summarization, task planning, research, content creation, and marketing strategy. By reducing the time spent on routine activities, users can focus on creativity, decision-making, and business growth.

This project was developed as part of the CAPACITI AI Skills Acceleration Programme.

---

## Features

### Productivity Tools
- Smart Email Generator
  - Generates professional emails
  - Supports different tones and audiences
  - Editable AI-generated output

- Meeting Notes Summarizer
  - Summarizes lengthy meeting notes
  - Extracts key points, action items, and deadlines

- AI Task Planner
  - Creates structured daily and weekly schedules
  - Prioritizes tasks based on importance and urgency

- AI Research Assistant
  - Summarizes articles, reports, and topics
  - Provides key insights and recommendations

### Content Creation Tools
- Caption Generator
- Hashtag Generator
- Content Ideas Generator
- Campaign Planner
- Content Calendar

### AI Assistant
- Interactive chatbot interface
- Supports workplace and marketing-related queries

### Responsible AI
- AI disclaimer included
- Encourages users to review and verify AI-generated content before use

## Setup Instructions

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/marketmate-ai.git
```

### 2. Open the Project

```bash
cd marketmate-ai
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open in Browser

Visit:

```text
http://localhost:5173
```

## Prompt Engineering Strategy

The project uses structured prompts to guide AI responses and improve output quality.

Examples include:
- Professional email generation
- Meeting note summarization
- Task prioritization
- Marketing research summaries
- Social media content creation

Prompts were refined to improve clarity, accuracy, and relevance.

---

## Responsible AI Considerations

The application includes responsible AI practices by:

- Informing users that AI outputs may contain inaccuracies
- Encouraging human review before publishing content
- Promoting ethical use of AI-generated information
- Reducing the risk of misinformation and bias
